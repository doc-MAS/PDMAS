PDMAS — Profiling for Distributing Multi-Agent Systems

Questionnaire de caractérisation orientée distribution

Cette interface est une implémentation du protocole PDMAS. Elle aide à renseigner de manière structurée les propriétés du modèle ; elle ne sélectionne pas directement une stratégie de distribution.

Les réponses renseignées pour les propriétés constituent, une fois structurées, le profil PDMAS du modèle. Certaines questions peuvent être non applicables selon le modèle étudié.
